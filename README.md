# llm-data-market-research-hub

可追溯的研究记忆与协作中心 —— LLM 数据市场谈判研究（Study A，V5.2 3×2 设计）。

## 用途

存放**研究过程资产**，使每一条结论都能回溯到具体文件、具体读数、具体日期。

| 放这里 | 不放这里 |
|---|---|
| 设计文档、变量口径、裁决记录 | 实验代码 → [cdmn-fcs](https://github.com/Rose2476830928/cdmn-fcs) |
| 文献笔记、引用核查 | 原始数据与付费模型读数（体积大） |
| 论文大纲、草稿、图表 | 任何形式的密钥、Token、`.env` |

## 目录约定

```
design/     实验设计、变量口径、裁决记录
notes/      工作笔记、日志、审查记录
literature/ 文献笔记与引用核查
papers/     论文大纲、草稿
archive/    冻结的历史版本（只读）
```

## 分支模型

- `main` —— 稳定快照，只接受 PR 合入
- `docs/<slug>` —— 文档与规范类改动
- `chore/<slug>` —— 仓库维护类改动
